# Code of conduct

We want this project to be useful, rigorous, and welcoming.

Be respectful, assume good intent, critique ideas rather than people, and make room for contributors with different languages and levels of experience. Harassment, discrimination, personal attacks, doxxing, and intentionally disruptive behavior are not acceptable in project spaces.

Maintainers may edit or remove contributions and restrict participation when behavior harms the community. Report sensitive conduct concerns privately through the maintainer’s [GitHub profile](https://github.com/alessiomarcone); do not publish personal details in an issue.
