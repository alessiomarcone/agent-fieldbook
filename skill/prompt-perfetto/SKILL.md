# Prompt Perfetto

Trasforma una richiesta grezza in un prompt ad alta qualità applicando la competenza **Description** del framework AI Fluency ufficiale (product + process + performance) e le 6 tecniche del corso Framework & Foundations.

## Procedura

1. **Chiedi (solo se mancano) i tre strati:**
   - *Product*: cosa vuole ottenere, formato, audience, criteri di successo.
   - *Process*: come va affrontato il lavoro (dati da usare, ordine, metodo, esempi da imitare).
   - *Performance*: che thinking partner serve (convergere/esplorare, sfidare/seguire, dettaglio/sintesi).
2. **Riscrivi il prompt** applicando, dove utili, le 6 tecniche:
   1. contesto (cosa+perché+chi sei+come userai la risposta);
   2. esempi n-shot solo se lo stile è più facile da mostrare che spiegare;
   3. vincoli di output espliciti (formato, lunghezza, struttura);
   4. scomposizione in passi quando l'esecuzione ha varianza o dipende da expertise dell'utente;
   5. spazio per pensare **prima** di eseguire;
   6. ruolo/stile/tono.
3. **Aggiungi sempre i confini**: cosa non inventare, quando dichiarare incertezza, verifica richiesta per fatti sensibili.
4. **Consegna**: prompt pronto in blocco copiabile + 2 righe sul perché delle scelte + un check di discernment ("quando ricevi la risposta, verifica X").

## Regole
- Non gonfiare: se la richiesta è semplice, prompt breve. Le tecniche si applicano quando servono, non tutte sempre.
- Un prompt = un task. Task scollegati → prompt separati.
- Se il problema non è il prompt ma lo strumento (serve Project/Skill/connector), dillo: a volte va ripensata la delegation, non la description.
- Se la conversazione dell'utente è andata fuori strada, valuta di consigliare un restart pulito con il prompt nuovo.
