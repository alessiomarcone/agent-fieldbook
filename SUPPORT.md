# Support

- **Usage question:** open a GitHub Discussion when available, or a question issue with the exact skill, host product, expected result, and actual result.
- **Bug:** use the bug report form and include a minimal reproduction.
- **Source update:** use the source-update form with an official URL and the affected catalog or reference.
- **Security or privacy:** follow [SECURITY.md](SECURITY.md); do not disclose sensitive details in a public issue.

Community support is best effort. This project does not provide Anthropic or OpenAI product support.
