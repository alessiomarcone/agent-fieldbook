# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Runtime model

The installed plugin contains instructions and reference files only. It ships no hooks, MCP servers, background processes, credentials, or automatically executed scripts. The repository-level catalog utilities run only when a maintainer invokes them.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/alessiomarcone/claude-knowledge-pack/security/advisories/new) for issues involving code execution, prompt injection in bundled content, unsafe installation behavior, or leaked data. Do not open a public issue containing exploit details.

Include the affected version, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgment within seven days.
