# Initial public submission

Agent Fieldbook began with a recurring gap: Claude could make a plausible
autonomous decision about project structure, while an official Anthropic course
would later teach a different current filename, mechanism, or operating pattern.
The plugin turns publicly available official learning material into ten focused,
source-backed workflows that are available during the work itself.

It routes ambiguous requests, improves prompts, verifies outputs, defines
product-correct subagents, builds reusable skills and plugins, designs Cowork
and Codex workflows, creates official learning paths, and distills knowledge
cards. It complements the original courses and links back to them; it does not
redistribute lessons or raw transcripts.

The plugin has no MCP server, authentication, hooks, telemetry, or autonomous runtime side effects. Version 1.0.0 includes native Claude and Codex manifests, deterministic packaging, dependency-free validation, source freshness checks, privacy and terms pages, starter prompts, and the required five positive and three negative review cases.
