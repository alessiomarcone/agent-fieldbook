## Descriptions

**Short description**

Turn official agent training into daily workflows.

**Long description**

Agent Fieldbook turns publicly available Anthropic training and current OpenAI
guidance into ten focused, multilingual skills that are available while the
agent works. They help users choose product-correct structures, write reliable
prompts, verify outputs, define subagents, build skills and plugins, operate
Cowork and Codex, follow official learning paths, and distill sources into
reusable knowledge cards.

## Starter prompts

1. Choose the structure official guidance supports for this workflow.
2. Turn this rough objective into a bounded, verifiable prompt.
3. Check whether this agent setup follows current product guidance.

## Trust and data handling

Agent Fieldbook is skills-only. It has no MCP server, app, authentication,
telemetry, hook, background process, or autonomous runtime side effect. It does
not collect or transmit personal data. Host actions remain governed by the
host product's permissions and the user's explicit task.

The repository contains original synthesis and links to third-party educational
material. It does not redistribute raw course lessons or transcripts.
